# msdanalyzer-tools - Small, useful tools for msdanalyzer
These are a small handful of tools I created for my research that work with [tinevez's msdanalyzer](https://github.com/tinevez/msdanalyzer). Enjoy!

### What's in the box
|File Location|Description|
|:---:|:---:|
|`converters/ma2trackAnalyzer.m`|A small script that converts msdanalyzer tracks to tracks [Track Analysis](https://github.com/andrewx101/track_analysis) understands.|
